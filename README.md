VÉLODEX 是一个由公路车爱好者维护的装车与升级工具。选择自己的车辆，搭配跨品牌零件，把报价、安装条件和重量口径放进同一份方案；保存不同配置，比较后再决定怎么装。车型资料、配件库和骑行科普为这些选择提供依据。

网站以真实照片和有出处的资料为基础，覆盖气动、全能、爬坡、耐力、砾石与 TT 计时车。同时收录经典车型、国产品牌、职业车队与车手资料，并持续补充更新。

## 骑车、做学术，也享受生活

喜欢公路车，也热爱骑行。我享受做学术时的思考与探索，也享受骑行时的风、沿途的风景，以及专注于当下的感觉。认真做研究，好好骑车，也好好生活。

VÉLODEX 是这份兴趣的延伸：把喜欢的车、想弄懂的设计和值得分享的知识整理在一起。希望它能成为车友偶尔来逛一逛、找到一点新发现的小地方。

## 从一份方案开始

首页直接进入装车台，不预设品牌、车型、预算或车重。既可从车型库选择，也可填写未收录的车辆和零件。

| 工作区     | 用途                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| 装车台     | 区分购入、沿用与拆下的零件；计算人民币报价、工时耗材和旧件转售后的净支出       |
| 选配件     | 搜索跨品牌配件，查阅销售版本、参数和价格来源，直接加入方案                     |
| 几何与把位 | 在相同毫米坐标下比较两副车架及把立、垫圈、车把前伸和坐垫参考点                 |
| 我的方案   | 自动保存草稿，另存配置并排对比，导入 / 导出方案文件，分享可编辑链接与 PNG 海报 |

**外观预览：** 保留原厂照片与已有涂装。以两根轮轴和轮胎外缘标定照片后，可叠加轮圈框高、轮径和胎侧的比例示意。它保留原图花鼓、辐条等细节，不是指定轮组的真实实装照片；不同照片需要分别标定。

**费用与重量：** 大陆官方参考价可计入人民币预算，海外价格明确地区、币种和日期，填写人民币到手价后再计入。缺项不按零处理；沿用件不重复计价。重量允许跳过，只有数据完整且新旧件称重范围一致时才给出升级后的整车估重；锁鞋等穿戴设备不默认计入车重。

**选配与询价：** 配件按厂商和报价地区筛选，同系列可直接切换具体规格。清单保留每个版本的型号和价格来源；车店询价单按已选零件列出接口、尺寸、随盒附件和费用范围，可导出文本交给车店。

**按预算挑选配件：** 填写整份方案的净预算和机动金额，选择这次要买的类别，或指定清单中要替换的一项。工具保留其余采购、沿用件和拆下件，计入工时、耗材与转售，再筛选预算内的候选。轮组可按框高、码表可按地图需求、功率计可按测量结构筛选；支持录入车店人民币报价，比较整单支出与替换差价。候选支持品牌与型号搜索、逐批展开、实物图放大，以及最多三款价格与规格并排比较。同款配件拿到新的车店报价后，也可直接替换价格而不重复加入清单。排序依据是公开价格或标称重量，不把未经同条件测试的产品排成性能榜。

费用汇总分别列出新件、工时、耗材与旧件转售抵扣，显示净预算占用与结余。手机可从底部费用栏直接打开明细、调整预算；未报价项目不会被当作零元。

**照片观察台：** 整车、涂装、车架与配件可放大、拖拽和并排查看，支持触控双指缩放、参考网格及原图比例，显示实际图片分辨率。有直接原图地址的素材可联网读取官网原图；不会把低分辨率素材伪装成高清细节。照片用于观察外观，几何尺寸仍以公开参数和毫米坐标对比为准。

**安装与几何：** 检查已收录的锁踏、锁片、鞋底孔位、设备协议、胎圈结构与部分轮组接口。未触发冲突不代表完整装配认证。把位工具采用公开车架几何和用户输入，未模拟手变角度、人体柔韧性或实际握持点，不能替代实车 fitting。

**资料共建：** [投稿与纠错](https://hliangzhao.me/velodex/?view=feedback&kind=correction)提供结构化模板，记录型号、版本、测量范围与来源。由读者自行发布到 GitHub Discussions，经维护者核对后进入正式资料库；不会自动发布或直接覆盖官方资料。

旧版工坊清单与收藏仍保留原存储位置，新装车台不覆盖它们。方案保存在当前设备，不自动上传；分享链接含清单、报价、备注与几何输入，打开后先预览，再由接收者决定是否载入。

## 骑行分析与训练

[训练工具](https://hliangzhao.me/velodex/?view=workshop&tool=power)在本机读取 TCX / GPX 的功率、心率和踏频。骑行分析、参考课表、训练记录与阻力估算采用独立页签。已核实的 FTP 可以主动保存在本机，下次自动使用；保存日期不作为测试日期，历史摘要仍保留当时的基准。先说明文件功率来自功率计、骑行台还是平台估算，再查看相应分析；没有功率数据也可以保存骑行时长和主观强度。

- 展示数据覆盖率、缺口和连续功率峰值；超过 5 秒的间隔不参与训练统计，5 秒峰值仅使用间隔不超过 1 秒的记录。
- 以自行填写的 FTP 划分功率区间。仅对连续完整且至少 10 分钟的功率记录计算估算 NP、IF 和 TSS，不把缺失数据补成零，也不从日常骑行均值推断 FTP。
- 结合本次强度分布和主观疲劳给出复盘提示；按恢复、耐力、节奏或阈值附近目标生成 30–90 分钟参考课表，可导出文本。模板不是个体训练处方。
- 本机保存最多 120 次骑行摘要，查看最近 7 天的已保存时长，支持导出、移除与撤销。摘要不含轨迹坐标或原始文件，不上传服务器。

最近七天的时长按本地自然日汇总，未保存摘要的日期不自动视作休息日。

计算方法附 [Coggan 功率区间](https://www.trainingpeaks.com/blog/power-training-levels/)与 [TrainingPeaks NP / IF / TSS 定义](https://help.trainingpeaks.com/hc/en-us/articles/204071804-Normalized-Power)。阻力模型仍保留在独立页签，用于探索体重、风况、CdA 和滚阻的影响；模型估算不用于训练负荷统计。

## 车型资料与查看方式

**部件参数：** 在官方整车照片上点击车架、手变、曲柄、牙盘、飞轮、功率计、轮组、轮胎、车把、座管或坐垫，查看对应版本的参数。多涂装车型可点击色块切换；“照片细看”支持放大与拖拽，也可隐藏热点查看完整外观。

**几何对比：** 逐尺码查看 Stack、Reach、角度、轴距等信息。在对比台上，以五通为共同原点叠加几何，观察前端高度与伸展的差异；分享链接保留车型顺序和各自尺码，方便继续讨论。

**车型演变：** [经典世代谱](https://hliangzhao.me/velodex/?view=generations) 收录 Tarmac、Madone、TCR 三个家族的 14 个精选节点，结合对应历史照片与同代参考车，比较前后节点的设计变化。节点注明年份依据，照片注明版本与出处。

**品牌与车型：** 图鉴涵盖 Specialized、Trek、Giant、Canyon、Cervélo、Cannondale、Colnago、Pinarello、Bianchi，以及喜德盛、银贝斯、速比特、瑞豹、坎普、西耐力和迪卡侬 Van Rysel 等品牌。从 CAAD13 铝架到 Topstone Lefty，从国产竞赛车到大环赛旗舰，可以沿不同兴趣继续探索。

[车手焦点](https://hliangzhao.me/velodex/?view=riders) 收录波加查、温格高、埃费内普尔、罗格利奇、皮德科克、沃勒林、维贝斯、科佩基等 16 位车手，提供比赛风格、观察提示和近期官方记录，并关联车队与车型。这是一份编辑精选，资料保留时间，不作为实时热度榜。

## 现车升级与选购参考

[现车升级指南](https://hliangzhao.me/velodex/?view=workshop&tool=advisor)从已有车辆出发，让读者自行选择净预算、路况、升级目标与现有设备。AD7 示例采用读者提供的 **¥13,980 / M 码约 8.44 kg**，数据可以修改；原装 C45 SL 重量未知时，不必为了继续比较而编一个数字。

配件库共十二类、**100 条产品与规格记录**，包括 ELILEE、VOSO 等轮组，迈金 / 思各异 / ELILEE / 4iiii / 佳明功率计，迹驰与迈金码表，速度踏频与心率传感器，以及锁踏、锁片和锁鞋。已有 **68 条配件参考价**：41 条国内官网展示价、6 条国内发布价，以及 21 条海外官网或官方代理商价格。

**价格优先采用中国大陆版本。** 没有可靠的大陆价格时，展示对应海外版本的原币种价格，并注明国家或地区、销售单位、来源和查阅日期。例如，VOSO Ultimate 50 的规格与日元价格对应日本代理商版本；ENVE SES 4.5 的美元价格为前后轮合计。整车与车架组分别记录，目前有 23 条整车、7 条车架组参考价；装车台另收录 5 个 SEKA 国内规格版本，可采用自己的车店报价。没有可靠价格的条目只展示产品资料，价格区域不设占位文字。

- 把新件、数量、工时、运费、适配件与耗材逐项计入；替换轮组时可扣除一次旧轮转售区间。缺报价时显示已知小计，避免误判为完整预算。
- 参考价按币种分组、组内排序。人民币价格可计入预算；海外价格保留原币种，填写实际人民币到手价后再计入，运费、税费与安装成本也可另行填写。
- 核对功率计测量方式、外设协议、锁踏与锁片制式、鞋底孔位；提示重复购买踏频传感器和普通锁踏等情况。
- 填写商家报价、年份、轮高、塔基、曲柄长度或鞋码，保存到浏览器、分享方案链接，或导出带来源与核对项的询价单。
- 提供轮组惯性、功率计测量、码表与传感器、锁鞋锁片四组选购说明。没有同条件测试，不以宣传参数制作性能排行榜。

| [骑行分析与训练](https://hliangzhao.me/velodex/?view=workshop&tool=power)    | 导入 GPX / TCX，检查功率、心率、踏频与数据覆盖；复盘训练、记录主观强度，导出参考课表，也可探索阻力模型。      |
| [结构观察室](https://hliangzhao.me/velodex/?view=workshop&tool=structures)   | 不同车架为什么长得不一样？旋转、缩放并叠加五类车架，观察 Ratchet EXP 啮合与轮圈胎圈截面。                     |

不必先知道每个零件的准确重量，才能开始装车。重量助手可选用有明确依据的官方数据，也可自填或跳过；缺项会保留为未知。预算以人民币记录，大陆参考价可一键采用；海外参考价明确显示地区和币种，由读者填写人民币到手价，不自动换汇。

装车海报中的整车照片代表所选的灵感平台，更换清单中的配件不会合成一张虚构的实装照片。

## 数据来源与使用范围

- **版本清楚。** 保留车型年、地区、具体配置、原厂来源与核对日期；没有可靠年份的版本单独列出。图片与文字配置不一致时注明差异，未公开的参数保留缺项。
- **比较有条件。** 零售版不等于车手赛日装配；不同厂商的重量与气动声明不直接组成性能排行榜。局部接口符合条件，也不等于整车已经获得安装认证。
- **模型各有用途。** 几何用于观察尺寸关系；风阻演示用于理解速度与 CdA；骑行功率估算受风况、海拔、跟骑及 GPS 误差影响，无法替代功率计。
- **精度边界：** 结构观察室与部分车型的实验性 3D 都是解释性模型，不是原厂 CAD、扫描模型或仿真结果，不能用于制造、精确拟合或测量装配间隙。

## 本地开发

前端使用 **React + TypeScript + Vite**，后端使用 **Express**，交互结构由 **Three.js** 绘制。源码在本地开发，网站通过 GitHub Pages 发布。

需要 **Node.js 22 或更高版本**：

```sh
git clone https://github.com/hliangzhao/velodex.git
cd velodex
npm ci
npm run dev
```

前端：[127.0.0.1:5173](http://127.0.0.1:5173) · API：[127.0.0.1:3001](http://127.0.0.1:3001) · 退出：`Ctrl+C`

| 命令                    | 用途                                                   |
| ----------------------- | ------------------------------------------------------ |
| `npm test`              | 检查 API、数据完整性、对比与分享、计算工具及 3D 网格。 |
| `npm run build`         | TypeScript 检查与本地生产构建。                        |
| `npm start`             | 使用 Express 提供构建后的页面与 API。                  |
| `npm run build:pages`   | 生成 GitHub Pages 静态版本。                           |
| `npm run preview:pages` | 在 `http://127.0.0.1:4173/velodex/` 预览静态版本。     |
| `npm run format`        | 使用 Prettier 整理格式。                               |

推送到 `main` 后，GitHub Actions 自动测试、构建并部署。Pages 直接读取构建时打包的资料，不需要常驻后端；本地模式继续使用 Express API。

部署参数、数据维护、API、工具计算与 3D 实现约定见 **[开发与维护文档](docs/development.md)**。整车与配件分别维护在 [catalog.json](server/data/catalog.json) 和 [parts.json](server/data/parts.json)。
